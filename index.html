01사례

공개 사례: artdg.com

옛 그누보드/영카트 쇼핑몰을 Next.js 정적 사이트로 이관·재구축했습니다. 처음부터 새로 만든 사이트가 아니며, 여러 고객사 납품 실적도 아닙니다. 공개 사례는 이 1건입니다.

네이버페이: 검수 중 연동 중(sandbox 검수 단계)입니다. 운영 주문 등록은 승인 전까지 닫혀 있고, 실제 결제 완료는 확인하지 않았습니다.

관리자 화면 5종

2026-11-04에 운영 관리자 화면을 직접 열어 촬영했습니다. 읽기만 했고 값은 바꾸지 않았습니다.

관리자 화면 목록은 코드 기준으로 확인한 것이고, 위 영상과 화면 5종 외에는 운영 화면을 직접 눌러 확인한 것이 아닙니다. 화면을 누르면 원본이 새 탭에서 열립니다.
