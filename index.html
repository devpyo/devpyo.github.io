공개 사례 1건: artdg.com

옛 그누보드/영카트 쇼핑몰을 Next.js 정적 사이트로 이관·재구축했습니다. 처음부터 새로 만든 사이트가 아니며, 여러 고객사 납품 실적도 아닙니다.

상품 135개, 상품정보 응답 52~170ms, 커밋 288개, 활동일 8일입니다. 저장소는 비공개여서 커밋 수와 활동일만 공개합니다.

  1. 1. 이관과 구조 상품 135개를 새 구조로 옮겼고, Cloudflare Workers와 D1에서 실행합니다.
  2. 2. 관리자와 안전장치 값 변경은 초안을 거쳐 발행하고, 가격 인하 한도와 변경 기록이 실수를 막습니다.
  3. 3. 주문과 네이버페이 연동 중(sandbox 검수 단계)입니다. 취소·반품·교환, 주문 상태 동기화는 아직 없습니다.
  4. 4. 납품 방식 소스와 디자인의 재사용 권리를 보유합니다. 테스트·배포·관리자 매뉴얼을 함께 인도합니다.

진행 방식

  1. 1. 범위와 완료 기준 (착수금)기능별 완료 기준을 착수 전에 문서로 정합니다.
  2. 2. 1~2주 단위 검수 (중도금)마일스톤마다 검수 가능한 결과물을 드립니다. 확인한 뒤 다음 단계로 넘어갑니다.
  3. 3. 인수인계 (잔금)테스트·배포·관리자 매뉴얼을 함께 인도하고, 소스 인수인계 범위를 계약서에 명시합니다.
  4. 4. 하자보수무상 하자보수 범위를 계약서에 명시합니다. 범위가 바뀌면 일정과 금액을 먼저 합의합니다.
